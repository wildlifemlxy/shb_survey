# WWF Project Management System

A web platform built for WWF Singapore's field teams to manage conservation survey projects end-to-end — from planning survey walks and logging field observations, to coordinating events, sharing photo evidence, and keeping team members updated in real time. It replaces scattered spreadsheets and manual messaging with a single dashboard covering data entry, analytics, and communication for each project.

The system currently supports two conservation initiatives:

- **Straw-Headed Bulbul** — wildlife monitoring through survey walks, event coordination, and photo documentation across Singapore's nature reserves and parks.
- **Rifle Range Road** — a conservation survey workspace for observations, field events, and project activity.

## Key Features

- **Survey data collection** — structured forms for logging field observations, with historical records viewable in sortable/filterable tables.
- **Dashboards & analytics** — charts and statistics summarizing survey trends over time for each project.
- **Interactive maps** — plots observation locations and points of interest using Google Maps/Leaflet.
- **Event scheduling** — a calendar/events view for coordinating upcoming survey walks and activities.
- **Photo gallery** — upload and browse field photos linked to Google Drive.
- **Telegram bot integration** — automated notifications and chat-based updates for field teams.
- **Secure login with MFA** — account access protected by multi-factor authentication.
- **Multi-project support** — a project switcher lets users move between initiatives they have access to.
